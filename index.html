Keyboard Shortcuts
Space or K
Play / Pause playback
N
Capture current timestamp and focus note input
← / →
Skip backward / forward 5 seconds
J / L
Skip backward / forward 10 seconds
, / . or [ / ]
Jump to previous / next annotation note
I / O
Set In Point / Out Point for range annotations
Shift + L
Toggle A-B range loop playback
Shift + , / .
Nudge the active note 0.1s earlier / later
Ctrl / ⌘ + Z
Undo the last note change (add, edit, delete, import, clear)
Ctrl / ⌘ + Shift + Z or Ctrl + Y
Redo the last undone change
+ / −
Zoom timeline in / out (or Ctrl + Scroll)
M
Mute / unmute audio
F
Toggle fullscreen video mode
P
Toggle Picture-in-Picture (video)
T
Toggle Light / Dark mode
Esc
Dismiss focus / close dialogs
